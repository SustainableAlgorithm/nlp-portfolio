MACHINE LEARNING · MODEL DEPLOYMENT

From trained model to usable application

This project demonstrates how a logistic-regression pipeline can be trained on historical Titanic passenger data, saved locally, and served through a Flask web interface.

Explore the demo

What happens behind the scenes?

  1. A local training script prepares age, sex, and passenger class.
  2. A scikit-learn pipeline imputes missing values and encodes categorical features.
  3. The trained pipeline is saved as a local joblib artifact.
  4. Flask validates the form input and returns the model's estimated survival probability.

Important limitations

This is an educational model using historical data. Its probability is not causal, not a guarantee, and not a statement about any individual. The data and features have important historical and ethical limitations.
